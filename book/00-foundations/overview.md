# 00 · Foundations

The bedrock for every later chapter. Two threads run through the whole book and both start here: **how different modalities land in one representation space** (alignment), and the **three generative paradigms** (autoregressive, diffusion, flow matching).

## Learning goals

- Understand how contrastive learning pulls images and text into a shared embedding space (the core idea of CLIP)
- Understand "tokenization" per modality: BPE for text, patches/VAE latents for images, codec tokens for audio
- Distinguish the three generative paradigms — their modeling targets, sampling procedures, and where each fits
- Run CLIP/SigLIP zero-shot classification and image-text retrieval yourself
